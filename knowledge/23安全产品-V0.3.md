## 📋 内容汇总
本文档系统介绍了三大类云安全产品：主机安全、DDoS高防和Web应用防火墙（WAF）。涵盖主机安全的功能特性（木马检测、异常登录、漏洞管理）、DDoS防护产品对比（基础防护、高防包、高防IP）、WAF产品分类（SaaS型、负载均衡型）以及高级防护功能（AI引擎、BOT管理、智能CC防护）。

## 🎯 知识要点
- 主机安全：基于机器学习的黑客入侵检测、漏洞风险预警、木马文件检测
- 主机安全功能：文件查杀、异常登录、密码破解、恶意请求、高危命令、本地提权、反弹Shell
- DDoS攻击类型：SYN Flood、ACK Flood、UDP Flood、ICMP Flood、反射型攻击
- CC攻击特点：应用层攻击，模拟正常用户访问消耗服务器CPU/内存资源
- DDoS防护产品：基础防护（免费2Gbps）、高防包（云内用户）、高防IP（全场景）
- WAF产品分类：SaaS型（DNS调度接入）、负载均衡型（CLB联动旁路检测）
- WAF防护能力：SQL注入、XSS跨站脚本、木马上传、CC攻击、DNS链路劫持
- 高级功能：AI+规则双引擎、BOT行为管理、智能CC防护、百G抗DDoS

## 💡 重点难点
- 主机安全vs网络安全：主机安全侧重系统层防护（木马、漏洞），网络安全侧重流量层防护（DDoS、CC）
- DDoS高防包与高防IP区别：高防包仅限云内用户且无需换IP，高防IP支持全场景但需修改DNS
- SaaS型与负载均衡型WAF：SaaS型通过DNS调度通用性强，负载均衡型与CLB联动延迟更低
- CC攻击识别：无明显异常流量，需分析源IP频率、访问模式、业务类型
- 封堵机制：攻击超出免费防护阈值时，为保护云平台整体网络会被封堵外网流量

## 第 12 页

DDOS攻击介绍
DDoS 攻击
分布式拒绝服务攻击（DistributedDenial of Service，DDoS）是指攻击者通过网络远程控制大量僵尸主机向一个或多个目标发送大量攻击请求，堵塞目标服务器的网络带宽或耗尽目标服务器的系统资源，导致其无法响应正常的服务请求。
网络层 DDoS 攻击
网络层 DDoS 攻击主要是指攻击者利用大流量攻击拥塞目标服务器的网络带宽，消耗服务器系统层资源，导致目标服务器无法正常响应客户访问的攻击方式。
常见攻击类型包括 SYN Flood、ACK Flood、UDP Flood、ICMPFlood及DNS/NTP/SSDP/memcached等反射型攻击。
DDoS攻击俗称流量攻击，是黑客利用自己控制的肉鸡，向目标服务器发起海量的虚假访问请求，从而占用服务器的带宽，让正常客户无法访问，业务被迫暂停。所以这种攻击能伪装成正常访问的数据，让普通的防护设备根本无法识别。
DDoS攻击成本较低，带宽峰值100G以下的攻击流量，用户只需付费几百元不等就能攻击一次或攻击一天。此现象常发生在同行之间的恶意竟争中，如游戏公司。但是购买带宽峰值的防护，一个月就要几千至几十万元不等。


## 第 13 页

CC攻击介绍
CC 攻击
CC 攻击主要是指通过恶意占用目标服务器应用层资源，消耗处理性能，导致其无法正常提供服务的攻击方式。
常见的攻击类型包括基于 HTTP/HTTPS 的 GET/POST Flood、四层 CC 以及 Connection Flood 等攻击方式。
CC攻击是DDoS攻击的其中一种，是黑客利用自己控制的肉鸡，向目标服务器发起大量伪装起来的虚假访问请求，从而占用消耗服务器的CPU、内存、硬盘、网络等资源，是目前应用层攻击的主要手段之一，借助代理服务器生成指向目标系统的合法请求，实现伪装。
我们都有这样的体验，访问一个静态页面，即使人多也不需要太长时间，但如果在高峰期访问论坛、贴吧等，那就很慢了，因为服务器系统需要到数据库中判断访问者否有读帖、发言等权限，访问的人越多，论坛的页面越多，数据库压力就越大，被访问的频率也越高，占用的系统资源也就相当可观。
而CC攻击就充分利用了这个特点，模拟多个正常用户不停地访问如论坛这些需要大量数据操作的页面，造成服务器资源的浪费，CPU长时间处于100%，永远都有处理不完的请求，网络拥塞，正常访问被中止。这种攻击技术性含量高，见不到真实源IP，见不到特别大的异常流量，但服务器就是无法进行正常连接。

## 第 27 页

DDOS高防常见问题
1、为什么进行封堵？
腾讯云通过共享基础设施的方式降低用云成本，所有用户共享腾讯云的外网出口。当发生大流量攻击时，除了会影响被攻击对象，整个腾讯云的网络都可能会受到影响。
为了避免攻击影响到其他未被攻击的用户，保障整个云平台网络的稳定，需要进行封堵。
2、为什么不提供免费无限抗攻击？
DDoS 攻击不仅影响受害者，也会对整个云网络造成严重影响，影响云内其它未被攻击的用户。
而DDoS 防御的成本非常高，一是带宽成本，二是清洗成本，其中最大的成本就是带宽费用，带宽费用以总流量计算，不会考虑是正常流量或是攻击流量而区别收费。因此，腾讯云在成本可承受的范围内为云服务用户提供免费的 DDoS 基础防护服务，当攻击流量超出免费防护阈值时，腾讯云会屏蔽被攻击 IP 的外网流量。
3、DDoS 高防包和 DDoS 高防 IP 的区别是什么？
防护对象：
DDoS 高防包只针对腾讯云内的服务提升 DDoS 防护能力。
DDoS 高防 IP 面向云内外用户，支持网站域名和业务端口接入防护。
接入：
DDoS 高防包的接入配置更加便捷，无需变更公网 IP 地址。
DDoS 高防 IP 需修改 DNS 解析或修改业务 IP 后才能接入防护。

## 第 29 页

WEB应用防火墙介绍
腾讯云 Web 应用防火墙（Web Application Firewall，WAF）帮助腾讯云内及云外用户应对 Web 攻击、入侵、漏洞利用、挂马、篡改、后门、爬虫等网站及 Web 业务安全防护问题。
企业通过部署腾讯云 WAF 服务，将 Web 攻击威胁压力转移到腾讯云 WAF 防护集群节点，分钟级获取腾讯 Web 业务防护能力，为网站及 Web 业务安全运营保驾护航。
注：BGP高防是唯一能防DDoS攻击的产品，同时也能防CC攻击，而WAF只能防CC攻击。


## 第 30 页

WAF的特性
WAF是一款基于 AI 的一站式 Web 业务运营风险防护方案。通过AI+规则双引擎识别恶意流量，保护网站安全，提高web站点的安全性和可靠性；通过BOT行为分析，防御恶意访问行为，保护网站核心业务安全和数据安全。
可防御攻击：SQL注入、XSS跨站脚本、木马上传、非授权访问、CC攻击、DNS链路劫持检测、0day漏洞补丁、防篡改。

## 第 37 页

WAF的高级功能
AI+规则双引擎防护
在安全规则引擎进行 OWASP Top10 防御（如 SQL 注入、非授权访问、XSS 跨站脚本、CSRF 跨站请求伪造、命令行注入等）的基础上，引入 AI 防御能力，通过交叉验证持续学习，精准有效捕捉各类常规 Web 攻击、0day 攻击及其它新型未知攻击。
通过不断学习海量业务数据特征，生成基于业务的个性化防护策略，避免误报，用户可基于 AI 引擎实现自助误报和漏报处理，提升运营效率。
BOT 行为管理
基于 AI 的行为分析引擎，实现实时会话追踪，通过流量画像匹配行为模型及行为标签，进行识别高效率检测恶意 BOT 行为。
提供超过1000种公开 BOT 类型，可快速设定防护策略。
提供爬虫和 IP 情报特征，快速识别 BOT 行为。
提供协议特征和50+会话特征，针对多种业务场景定义防护策略。
提供已知、未知和自定义类型 BOT 详细报表和统计，快速定位和防御恶意 BOT，保护网站业务安全。
智能 CC 防护
综合源站异常响应情况（超时、响应延迟）和网站历史访问数据，智能决策生成防御策略，实时拦截高频访问请求，封禁攻击源。
可自定义 session，通过 session 维度进行 CC 防护，更加精确防护 CC 攻击，减少误报。
可实时查看 CC 封堵状态 IP，根据需要快速调整防护策略。
一键无缝接入百 G 抗 DDoS 攻击能力，轻松应对敏感大流量 DDoS 攻击问题，无惧突发风险。
