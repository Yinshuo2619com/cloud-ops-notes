## 第 4 页

什么是对象存储
对象存储是由云服务商推出的无目录层次结构、无数据格式限制，可容纳海量数据且支持 HTTP/HTTPS 协议访问的分布式存储服务。对象存储的存储桶空间无容量上限，无需分区管理，适用于 CDN 数据分发、数据万象处理或大数据计算与分析的数据湖等多种场景。
对象存储可通过 控制台、API、SDK、工具 等多样化方式简单、快速地接入，实现了海量数据存储和管理。通过对象存储可以进行任意格式文件的上传、下载和管理。云服务商提供了直观的 Web 管理界面，同时提供遍布全国范围的 CDN 节点可以对文件下载进行加速。其实简单点说，可以将对象存储理解为一个云端网盘，但是它所提供的功能却比网盘多很多，且使用会更加灵活多变。

## 第 6 页

基本概念
存储桶（Bucket）
存储桶（Bucket）是对象的载体，可理解为存放对象的“容器”。用户可以通过云控制台、API、SDK 等多种方式管理存储桶以及配置属性。
对象（Object）
对象（Object）是对象存储的基本单元，对象被存放到存储桶中。用户可以通过云控制台、API、SDK 等多种方式管理对象。对象实际就是我们存储的数据文件。
APPID
APPID 是您云账号的唯一标识符，是与账号 ID 有唯一对应关系的应用 ID。可用在存储桶名称上，例如存储桶名称examplebucket-1250000000 中的 1250000000 即为 APPID。
Secret Key/SecretId
SecretId 和 SecretKey 合称为云 API 密钥，是用户访问腾讯云 API 进行身份验证时需要用到的安全凭证，可在 API 密钥管理 中获取。一个 APPID 可以创建多个云 API 密钥。
SecretId 用于标识 API 调用者身份，SecretKey 是用于加密签名字符串和服务器端验证签名字符串的密钥。


## 第 7 页

基本概念
Region
即地域，是云托管机房的分布地区，对象存储 COS 的数据存放在这些地域的存储桶中。
policy
策略（policy）由若干元素构成，用来描述授权的具体信息。
外网下行流量
指数据通过互联网从对象存储传输到客户端产生的流量，包括用户直接通过对象链接下载对象或通过静态网站源站浏览对象产生的流量。
CDN 回源流量
指数据从对象存储传输到云内容分发网络（Content Delivery Network，CDN）边缘节点产生的流量。
默认域名
即对象存储源站域名，是创建存储桶时，由系统根据存储桶名称和地域自动生成的，要与默认加速域名区分开。
自定义 CDN 加速域名
用户可以为存储桶，绑定已备案的自定义域名至腾讯云国内 CDN 加速平台，通过自定义域名加速访问存储桶中的对象。
自定义源站域名
用户可以将已备案的自定义域名，绑定至当前存储桶，通过自定义域名访问存储桶内对象。

## 第 11 页

计费概述
对象存储支持按量计费（后付费）和资源包（预付费）两种计费方式，由 存储容量费用、请求费用、数据取回费用、流量费用 和 管理功能费用 组成。
计费类型 | 计费类目 | 释义
--- | --- | ---
存储容量 | 标准存储 低频存储 归档存储 深度归档存储 | 采用那种存储方式，就收取那种存储费用
流量 | 流出到客户端 流出到CDN节点 | 只要从对象存储出来的流量就要计费，但计费价格会有不同
请求数 | QPS | 网站文件数量决定，访问1个文件页面，这个文件页面可能还调用了其他文件，所以实际可能是多次请求
数据取回 | 归档存储 深度归档存储 | 有最短存储时间限制，不足最短存储时间会按照最短时间进行扣费
管理功能 | 清单功能 检索功能 批量处理 等 | 一般用不到
其他 | 由其他产品提供功能 | 由其他产品进行扣费，如内容审核、图片水印、加密


## 第 12 页

免费额度
对象存储面向所有新用户（即首次开通对象存储服务的个人和企业用户）提供一定量的免费额度资源包，可用于抵扣标准存储类型的数据产生的标准存储容量费用。免费额度资源包明细请参见下表。
按照地域范围，免费额度只适用于公有云地域，不包含金融云地域
用户在享有免费额度期间产生的低频存储/归档存储容量、请求、流量等非标准存储容量计费项，不属于免费范畴。
用户在享有免费额度期间由于违禁原因停服、欠费停服后，将不能继续享受免费额度，只有服务重新开启后才可继续享受免费额度。
存储量以二进制计算，例如1TB = 1024GB。

## 第 30 页

常见问题分析
问题1：通过外网上传文件至COS缓慢
原因分析：
中国大陆公有云地域单账号默认带宽：上行和下行各自为15Gbit/s，其他地域单账号默认带宽：上行和下行各自为10Gbit/s；
所以问题一般在客户端本地网络带宽限制，或运营商传输线路不稳定
① 运营商线路 通过ping测试，延时稳定不丢包即正常，大部分原因都是客户端本地带宽限制
② 客户端环境一般有：家庭带宽、公司带宽、手机信号带宽
如：家用带宽，假设客户家里办理了电信千兆带宽（1024Mbps），但实际上传文件至COS的传输速率最大只有2.5MB/s（20Mbps），这是因为家用买的千兆带宽是下行，而上行是运营商默认分配（一般在8-50Mbps之间，具体大小需自己办理带宽的运营商），上传文件至COS会受到家用上行带宽限制，故上传速率在8-50Mbps，取决于运营商默认分配的带宽大小。


## 第 31 页

常见问题分析
问题2：通过外网访问COS文件缓慢
同上问题原理一样，COS产品提供了足够大的带宽，但实际传输能达到多大的带宽，取决于客户本地网络带宽限制 或 运营商网络稳定性
但上传和访问不一样，上传使用的是客户端上行带宽，而访问用的是客户端下行带宽（即向运营商购买的带宽），以家用带宽千兆为例，访问COS的最大带宽就是千兆。
