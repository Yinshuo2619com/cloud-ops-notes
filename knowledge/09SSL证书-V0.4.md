## 📋 内容汇总
本文档全面介绍了SSL证书的基本概念、工作原理、应用场景以及实际部署方法。涵盖SSL证书的定义、加密传输机制、证书颁发机构（CA）、证书分类、计费方式以及在Nginx服务器上的配置部署，是实现HTTPS加密访问的完整指南。

## 🎯 知识要点
- SSL证书定义：数字证书，用于在客户端与服务端之间建立安全加密通道
- 加密传输原理：HTTP明文协议升级为HTTPS加密协议，防止数据泄露和篡改
- 证书颁发机构：全球信任的CA机构颁发的证书才被浏览器信任
- 证书分类：免费型证书（1年期限）与付费型证书（最长3年，需年度更新）
- 申请流程：绑定域名、选择验证方式、联系邮箱等简单步骤
- 部署配置：下载证书文件、上传服务器、配置Nginx的SSL相关参数
- Nginx配置：listen 443 ssl、ssl_certificate、ssl_certificate_key等关键指令
- 工具查询：使用myssl.com等平台验证证书状态和配置

## 💡 重点难点
- 证书信任机制：理解为什么自签发证书不被信任，CA证书的内置原理
- 证书类型选择：免费型与付费型的区别，根据业务需求选择合适类型
- HTTPS配置流程：从证书申请到Nginx配置的完整操作步骤
- 证书更新策略：免费证书需年度重新申请，付费证书需年度更新配置
- 加密协议配置：TLSv1.2/TLSv1.3协议选择与加密套件配置

## 第 4 页

SSL证书介绍
什么是SSL证书？
SSL证书，也称为服务器证书，是遵守SSL协议的一种数字证书，由全球信任的证书颁发机构(CA)验证身份后颁发，将SSL证书安装在网站服务器上，会激活挂锁和https协议，通过https协议传输，是http明文协议升级https加密协议必备的数字证书，它在客户端（浏览器）与服务端（网站服务器）之间搭建一条安全的加密通道，对两者之间交换的信息进行加密，确保传输数据不被泄露或篡改。简单理解：SSL证书可以将‘本地电脑’访问‘网站’时互相传输的数据进行加密。● SSL证书在互联网上非常重要，因为它们可以防止黑客和攻击者截取和窃取用户的敏感信息。例如，当用户在购物网站输入信用卡信息或登录银行账户时，SSL证书可以确保这些数据被加密，并且只有目标网站才能够解密和使用这些数据。
● 任何个人或企业也可以自主颁发SSL证书，但是不被信任，只有通过全球信任的证书颁发机构(CA) 颁发的SSL证书才被信任。因为全球信任的证书颁发机构的CA证书默认内置在我们的操作系统或者浏览器或者网站应用中，而一般的个人或企业无法实现这一目的。当然，如果企业有足够自信能够保证用户安全访问，不会流失用户，也可以自签发证书使用，如：12306。

## 第 10 页

计费与年限
SSL证书价格
● 根据不同的域名类型、域名数量，对应的价格各有差异，一般从几百至上百万不等；
● 也有一种免费SSL证书，我们一般都会使用免费型SSL证书，除非因为业务特性问题必须用指定类型的SSL证书。如：银行、交易平台等。重要提醒：已经由 CA 机构成功颁发的 SSL 证书无法申请退款，已完成订单支付但申请失败、审核流程中止、且未成功颁发的证书可申请退款。
SSL证书使用年数限制
● 免费型SSL证书默认都只有1年期限，到期后就要重新申请，可以一直循环，但同时拥有的免费型证书数量有上限；● 付费型SSL证书最长可以买3年，但是每年都得重新颁发新的SSL证书并配置替换旧的SSL证书，只是不用在缴费而已。

## 第 14 页

SSL证书部署
以Centos7系统安装nginx配置SSL证书为例：1、从SSL证书平台下载nginx的SSL证书文件到本地电脑2、登录Centos云服务器系统安装nginx、lrzsz：yum -y install nginx lrzsz    （ lrzsz 用于传输小文件 ）
3、在Centos云服务器系统执行rz命令将对应的SSL证书文件上传到云服务器的/root/ssl目录下,若无该目录，自行创建（mkdir /root/ssl）
4、编辑nginx配置文件（vi /etc/nginx/conf.d/defaults.conf）并添加如下内容后，保存重启nginx服务即可（需注意，nginx版本不同，配置文件写法不同）
server {
listen 443 ssl;     # 443是ssl证书的https协议端口
server_name www.example.com;      #www.example.com   SSL证书绑定的域名
root  /usr/share/nginx/html;        #网站目录
index  index.html index.htm index.php;        #网站首页/索引文件
ssl_certificate /root/ssl/www.example.com_bundle.crt;     #SSL证书的公钥内容
ssl_certificate_key /root/ssl/www.example.com.key;       #SSL证书的私钥内容
ssl_session_timeout 5m;
ssl_protocols TLSv1.2 TLSv1.3;
ssl_ciphers ECDHE-RSA-AES128-GCM-SHA256:HIGH:!aNULL:!MD5:!RC4:!DHE;
ssl_prefer_server_ciphers on;
}
