# 云计算运维学习笔记

> 云计算运维工程师学习过程记录，涵盖腾讯云微专业认证培训内容与题库整理。

[页面访问](https://yinshuo2619com.github.io/cloud-ops-notes/)`https://yinshuo2619com.github.io/cloud-ops-notes/`

## 学习内容

### 腾讯云微专业认证

| 认证方向 | 核心知识点 |
|---------|-----------|
| 云基础 | 云计算概念、云服务器管理、IAM 权限管理 |
| 云网络 | VPC 网络架构、子网规划、路由表配置、NAT 网关 |
| 云安全 | 安全组策略、WAF 防护、DDoS 防御、SSL 证书 |
| 云数据库 | MySQL 管理、TencentDB 使用、备份恢复 |
| 云应用 | 云原生应用部署、容器服务、微服务架构 |

### 知识库覆盖范围

- 操作系统运维基础与工具
- 云服务器与云硬盘管理
- 域名、DNS 解析、SSL 证书、备案
- 网络运维基础、私有网络、网络连接
- 云负载均衡
- 云数据库（MySQL、Redis）
- 对象存储与 CDN 加速
- 安全防护与安全产品

## 题库说明

`history/` 目录下的题库来自青书云考试平台，包含：

- **云应用**：30 单选 + 10 多选，100 分
- **云基础**：30 单选 + 10 多选，100 分
- **云数据库**：30 单选 + 10 多选，100 分
- **云网络**：30 单选 + 10 多选，100 分
